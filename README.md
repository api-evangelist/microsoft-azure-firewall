# Azure Firewall (microsoft-azure-firewall)

Azure Firewall is a managed cloud-based network security service that protects your Azure Virtual Network resources. The REST API supports configuring network rules, application rules, NAT rules, and DNS proxy settings, with built-in high availability, unrestricted cloud scalability, and threat intelligence-based filtering.

### Azure Firewall REST API

Azure Firewall REST API provides management of cloud-native network security with built-in high availability, unrestricted cloud scalability, and threat intelligence-based filtering. It supports configuring network rules, application rules, NAT rules, and DNS proxy settings.
